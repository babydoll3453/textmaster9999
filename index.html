FAQ

Questions, answered.

Is this text repeater really free?

Yes — completely free. No signup, no account, no usage limits. Everything runs in your browser.

How many times can I repeat text?

Up to 100,000 repetitions per generation. The tool warns you if output is too large for a safe preview.

What is {n} and how does auto-numbering work?

Place {n} anywhere in your text. When numbering is enabled, each copy replaces it with an incrementing number. If there is no {n}, the number is added before or after each copy.

Can I use custom separators like \n or \t?

Yes. Select Custom and type \n for a new line or \t for a tab.

Is my text sent to a server?

No. Processing happens locally in your browser. Your text never leaves your device.

What can I use this tool for?

Generating test data, numbered lists, CSV rows, repeating emojis, testing input fields and handwriting practice.
